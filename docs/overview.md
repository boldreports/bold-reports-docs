# Bold Reports<sup>®</sup> On-Premises Edition overview

Bold Reports<sup>®</sup> On-Premises Edition is an end-to-end solution for creating, managing, and sharing interactive business reports. It includes a Web Report Designer for composing reports.

## What is Bold Reports<sup>®</sup> On-Premises Edition?

Bold Reports<sup>®</sup> is an online solution for analyzing data in web applications using interactive reports with key metrics. The On-Premises Edition includes Bold Reports<sup>®</sup> Report Server and a Web Report Designer for composing reports.

## What are the key features of Bold Reports<sup>®</sup> Report Server?

Bold Reports<sup>®</sup> Report Server offers the following key features for managing, viewing, and sharing reports.

**Report management:** You can organize reports efficiently under categories. You can grant permission to view the reports to specific users or groups.

**Business-user-friendly:** The user-friendly drag-and-drop report designer enables business users to create and publish reports without assistance from IT.

**Cost effective licensing:** The licensing cost is effective for both small and large teams. Check the [Bold Reports<sup>®</sup> pricing plans](https://www.boldreports.com/pricing/).

**Multi-site:** Multi-site mode provides a convenient, cost-effective method for deploying the report solution to multiple sites.

**Versioning:** All items stored in the Bold Reports<sup>®</sup> Report Server are versioned, so you can revert to an older version.

**User management:** You can organize users into groups to accurately map the structure of small and large organizations.

**Scheduling:** Reports can be generated and emailed according to a schedule. The scheduling functionality is flexible.

**Flexible permissions:** A flexible permission scheme controls access to read, write, and delete reports.

**View reports:** The built-in HTML5 RDL Report Viewer control lets users view reports through the browser.

**Export:** You can export RDL reports to Excel, Word, PDF, and HTML file formats.

**Custom branding:** The Report Server includes customization capabilities that let you add your organization’s name, logo, welcome note, and other branding elements.
