# REST API for Bold Reports<sup>®</sup> Report Server

Using the Bold Reports<sup>®</sup> on-premises REST API, you can manage and change resources programmatically via HTTP. The API provides access to the functionality behind these resources.

## What can I build with the Report Server REST API?

The Bold Reports<sup>®</sup> REST API lets you create custom applications or script interactions with Bold Reports<sup>®</sup> resources.
