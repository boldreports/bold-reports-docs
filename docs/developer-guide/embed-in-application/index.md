# Embed Bold Reports<sup>®</sup> Report Server in your application

You can integrate Bold Reports<sup>®</sup> Report Server reporting into your application through the REST API, the reporting components, or an embed URL. Bold Reports<sup>®</sup> provides a comprehensive set of APIs for server integration.

## Which integration options can I use?

Bold Reports<sup>®</sup> Report Server offers three options for integrating reporting features into your applications: REST API, Reporting Component, and Embed URL. Each option provides a different approach to the integration, as the following sections explain.

## REST API

Bold Reports<sup>®</sup> Report Server has a built-in REST API that lets you manage Report Server features from your application. You can learn more from the <a href="../../rest-api-reference/v1.0/server-api-reference/" target="_blank">REST API reference</a> and the following articles:

1. [Generate authentication token from Report Server UI](./../how-to/generate-authentication-token-for-bold-reports-server/).
2. [Generate authentication token from Report Server API](./../../developer-guide/how-to/generate-authentication-token-for-bold-reports-server-using-credentials/).
3. [Get list of Reports from Report server](../../developer-guide/how-to/get-list-of-items-from-bold-reports-server/)
4. [Export report from Report Server](./../../developer-guide/how-to/export-report-from-bold-reports-server/)

## Reporting Components

Bold Reports<sup>®</sup> provides Embedded Reporting Tools for integrating report viewing and editing into your application. The components let you view and edit reports with Report Server along with the built-in Report Service. You can learn more in the following sections:

* [View report through Report Viewer](./../embed-in-application/view-report-through-report-viewer/)
* [Integrating Web Report Designer](./../embed-in-application/integrating-report-designer/)

## Embed URL

URL access is another Bold Reports<sup>®</sup> option for integrating report viewing into your applications. You generate the embed URL from the embed code and use it with an iFrame to embed report viewing in your application. You can learn more in the following sections:

[Get Embed Code of Report](./../embed-in-application/iframe/embed-code-of-report/)

[Embed report using embed secret key](./../embed-in-application/iframe/embed-secret-key/)
