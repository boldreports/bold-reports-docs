# Embed Report Server reports using an iframe

Bold Reports<sup>®</sup> Report Server lets you embed reports into another application using an iframe and the embed URL. You get the embed URL from a report's embed code, and you can sign it with an embed secret key for SSO.

## Which iframe embedding options are available?

Bold Reports<sup>®</sup> Report Server offers two ways to embed a report in an iframe:

* Use the embed code of a report, which gives you an embed URL for public or private embedding.
* Use the embed secret key to sign the embed URL for single sign-on (SSO).
