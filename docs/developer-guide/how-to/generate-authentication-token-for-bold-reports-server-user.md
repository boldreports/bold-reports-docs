# How to generate the authentication token for Bold Reports<sup>®</sup> Report Server user

Bold Reports<sup>®</sup> Report Server offers three options for generating a user authentication token: the Report Server UI, user credentials, and the Embed Secret Key API.

## Which token generation option should I use?

Each Bold Reports<sup>®</sup> Report Server token option has its own guide:
