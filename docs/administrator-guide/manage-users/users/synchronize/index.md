# Synchronize users in Bold Reports<sup>®</sup> Report Server

You can synchronize Active Directory, Microsoft Entra ID (formerly Azure Active Directory), and Database users to the Bold Reports<sup>®</sup> Report Server.

## Which user sources can I synchronize?

The Bold Reports<sup>®</sup> Report Server synchronizes users from Active Directory, Microsoft Entra ID, and an existing database. Learn more details from the following sections:

* [Synchronize users from Microsoft Entra ID](./../synchronize/synchronize-azure-active-directory-users/)

* [Synchronize users from Database](./../synchronize/synchronize-existing-database-users/)
