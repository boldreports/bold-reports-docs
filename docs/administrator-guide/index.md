# Bold Reports<sup>®</sup> Report Server administrator guide overview

Bold Reports<sup>®</sup> Report Server is an online solution for analyzing data on the web. You use interactive reports with key metrics to track business performance.

Bold Reports<sup>®</sup> is an end-to-end solution for creating, managing, and sharing interactive business reports. It includes a Web Report Designer for composing reports.

## What are the key features of Bold Reports<sup>®</sup> Report Server?

Bold Reports<sup>®</sup> Report Server provides report management, scheduling, exporting, user management, and branding features in one server.

**Report management**: You can organize reports under categories. You can grant permission to view reports to specific users or groups.

**Business user friendly**: The drag-and-drop report designer lets business users compose and publish reports without help from IT.

**Cost effective licensing**: The licensing cost is effective for both small and large teams. Check the [pricing plans](https://www.boldreports.com/pricing/).

**Multi-site**: Multi-site mode provides a convenient, cost-effective method for deploying the report solution to multiple sites.

**Versioning**: All items stored in the Report Server are versioned, so you can revert to an older version.

**User management**: You can organize users into groups to map the structure of small and large organizations.

**Scheduling**: You can generate and email reports on a schedule. The scheduling functionality is flexible.

**Flexible permissions**: A flexible permission scheme controls access to read, write, and delete reports.

**View reports**: The built-in HTML5 RDL Report Viewer control lets users view reports through the browser.

**Export**: You can export RDL reports to Excel, Word, PDF, and HTML formats.

**Custom branding**: Report Server has built-in customization capabilities that let you add your organization’s name, logo, welcome note, and more.
