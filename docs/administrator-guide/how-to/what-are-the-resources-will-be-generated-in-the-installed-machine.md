# What resources will be generated in the installed machine?

Bold Reports<sup>®</sup> generates four resource folders on the installed machine: Resources, Scheduler Service, Content, and Logs. Each folder stores a different type of application data.

## Resources

The Resources folder stores the reports, data sources, and datasets that you add in the Bold Reports<sup>®</sup> application.

## Scheduler Service

The Scheduler Service folder in Bold Reports<sup>®</sup> stores exported reports that are to be emailed, along with scheduling configurations.

## Content

The Content folder in Bold Reports<sup>®</sup> holds profile pictures and application images.

## Logs

The Logs folder lets you log errors and debug information from the Bold Reports<sup>®</sup> application for troubleshooting.
