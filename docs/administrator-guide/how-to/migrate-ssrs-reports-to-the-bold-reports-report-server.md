# How to migrate SSRS reports to the Bold Reports<sup>®</sup> Report Server

You migrate SSRS reports to the Bold Reports<sup>®</sup> Report Server by manually uploading each report together with its required dataset and data source.

## How do I upload SSRS reports, datasets, and data sources?

The Bold Reports<sup>®</sup> Report Server needs the report, its dataset, and its data source. The following guides show how to upload or create each item:

* [Upload Report](../../../designer-guide/manage-content/reports/upload-reports/)

* [Upload Dataset](../../../designer-guide/manage-content/dataset-management/#add-or-upload-dataset)

* [Create Data source](../../../designer-guide/manage-content/data-sources-management/#add-or-create-data-sources)

## Frequently asked questions

### Does the Report Server migrate SSRS reports automatically?

No. You manually upload each report and its required dataset and data source to the Bold Reports<sup>®</sup> Report Server.
