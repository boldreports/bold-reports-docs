# Centralized report authoring in Bold Reports<sup>®</sup> Report Server

Yes. Bold Reports<sup>®</sup> Report Server, in On-Premises and Cloud versions, gives report authors and developers one centralized location for report authoring.

## Does Bold Reports<sup>®</sup> have a centralized report authoring system?

Yes. Bold Reports<sup>®</sup> offers an On-Premises Edition and a Cloud Edition Report Server that keep your reports in centralized report authoring.
