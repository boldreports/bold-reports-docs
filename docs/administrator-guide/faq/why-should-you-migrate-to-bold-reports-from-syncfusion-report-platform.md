# Why should you migrate to Bold Reports<sup>®</sup> from Syncfusion<sup>®</sup> Report Platform?

You should migrate to Bold Reports<sup>®</sup> because Syncfusion<sup>®</sup> Report Platform will get no further feature updates.

## What is Bold Reports<sup>®</sup> and why was it introduced?

Bold Reports<sup>®</sup> is the separate suite for the reporting platform that Syncfusion<sup>®</sup> introduced. Because of the migration to Bold Reports<sup>®</sup>, there will be no further feature updates for Syncfusion<sup>®</sup> Report Platform. So, consider using Bold Reports<sup>®</sup> for your developments.
