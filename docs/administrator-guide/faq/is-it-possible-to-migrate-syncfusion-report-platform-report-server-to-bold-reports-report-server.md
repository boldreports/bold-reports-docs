# Is it possible to migrate from Syncfusion<sup>®</sup> Report Platform Report Server to Bold Reports<sup>®</sup> Report Server?

Yes. You can migrate from Syncfusion<sup>®</sup> Report Platform Report Server to Bold Reports<sup>®</sup> Report Server with the Data Migration utility. The migration is supported from Syncfusion<sup>®</sup> Report Server version `4.x`.

## Can I migrate Bold Reports<sup>®</sup> v1.x to v2.x?

Yes. You can also migrate Bold Reports<sup>®</sup> `v1.x` to Bold Reports<sup>®</sup> `v2.x`.

## Frequently asked questions

### Which tool do I use to migrate to Bold Reports<sup>®</sup> Report Server?

Use the Bold Reports<sup>®</sup> Data Migration utility to migrate from Syncfusion<sup>®</sup> Report Platform Report Server.

### Which Syncfusion<sup>®</sup> Report Server version can I migrate from?

Migration to Bold Reports<sup>®</sup> Report Server is supported from Syncfusion<sup>®</sup> Report Server version `4.x`.
