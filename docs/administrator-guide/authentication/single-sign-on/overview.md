# What is single sign-on in Bold Reports<sup>®</sup>?

Single sign-on (SSO) in Bold Reports<sup>®</sup> lets users authenticate with multiple applications and websites using one set of credentials. Users no longer need to log in separately to different applications.

With a single security token (a username and password pair), you can manage user access to multiple systems, apps, and resources. SSO reduces the time-consuming need to log in to each application with different passwords.
