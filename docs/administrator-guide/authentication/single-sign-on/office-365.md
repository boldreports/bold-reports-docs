# Office 365 authentication in Bold Reports<sup>®</sup> Report Server

Bold Reports<sup>®</sup> On-Premises Edition lets Office 365 users sign in with single sign-on (federated identity) by importing them from Microsoft Entra ID (formerly Azure AD). Reports can be shared or emailed with Office 365 users and groups.

As a result, the Report Server enables the importation of Office 365 users and groups, allowing them to sign in effortlessly.

## Which Microsoft Entra ID functions does Report Server support?

The Bold Reports<sup>®</sup> Report Server supports the following functions from Microsoft Entra ID:

* [Set up Microsoft Entra ID](./../../../manage-app-settings/azure-active-directory/) settings with Bold Reports<sup>®</sup> On-Premises Edition.

* [Import users](./../../../manage-users/users/import-users/import-azure-active-directory-users/) from Microsoft Entra ID.

* [Import groups](./../../../manage-users/groups/import-groups/import-azure-active-directory-groups/) from Active Directory.

* [Synchronize user details](./../../../manage-users/users/synchronize/synchronize-azure-active-directory-users/) with Microsoft Entra ID.

* [Synchronize group details and its users](./../../../manage-users/groups/synchronize/synchronize-azure-active-directory-groups/) with Microsoft Entra ID.

* [Schedule the synchronization of users and groups](./../../../manage-app-settings/synchronization-schedule/azure-active-directory-synchronization-schedule/) between Bold Reports<sup>®</sup> On-Premises Edition and Microsoft Entra ID.

## Frequently asked questions

### How do Office 365 users sign in to Bold Reports<sup>®</sup>?

Office 365 users sign in to Bold Reports<sup>®</sup> On-Premises Edition with single sign-on (federated identity). You import them from Microsoft Entra ID (formerly Azure AD).

### Can I share reports with Office 365 users and groups?

Yes. In Bold Reports<sup>®</sup> On-Premises Edition, reports can be shared or emailed with Office 365 users and groups.
