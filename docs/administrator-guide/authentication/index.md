# Authentication settings in Bold Reports<sup>®</sup> Report Server

Bold Reports<sup>®</sup> Authentication Settings let you configure Single Sign-On (SSO) for your Bold Reports<sup>®</sup> Report Server users.

## How do I configure single sign-on in Bold Reports<sup>®</sup>?

You configure single sign-on in Bold Reports<sup>®</sup> from the Authentication Settings. For more details, see the Single Sign-On section.
