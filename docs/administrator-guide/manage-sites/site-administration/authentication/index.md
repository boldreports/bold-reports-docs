# Authentication providers in Bold Reports<sup>®</sup> User Management Server

The Bold Reports<sup>®</sup> User Management Server supports Default Authentication, Microsoft Entra ID (formerly Azure AD), OAuth 2.0, OpenID, and JWT SSO for user sign-in.

## Which authentication options can I configure?

You can configure the following authentication options in the Bold Reports<sup>®</sup> User Management Server:

[OAuth 2.0 Support](./../authentication/oauth-2.0-support/)
