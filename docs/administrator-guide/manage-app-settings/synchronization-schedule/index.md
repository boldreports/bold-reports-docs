# User synchronization schedule in Bold Reports<sup>®</sup> Report Server

The synchronization schedule synchronizes users to the Bold Reports<sup>®</sup> Report Server on a scheduled basis. You can synchronize Active Directory, Microsoft Entra ID, and database users to the Report Server with the synchronization schedule.

## Which user sources can I synchronize on a schedule?

Bold Reports<sup>®</sup> Report Server supports synchronization schedules for the following user sources:

* [Windows Active Directory Synchronization Schedule](./../synchronization-schedule/active-directory-synchronization-schedule/)

* [Microsoft Entra ID Synchronization Schedule](./../synchronization-schedule/azure-active-directory-synchronization-schedule/)

* [Database Synchronization Schedule](./../synchronization-schedule/database-synchronization-schedule/)
