# Bold Reports<sup>®</sup> Report Server REST API v2.0

The Bold Reports<sup>®</sup> REST API v2.0 lets you add users and copy report items on your Bold Reports<sup>®</sup> site.

> **Important:** REST API v1.0 to v4.0 will be deprecated from the Bold Reports<sup>®</sup> release planned for November 2026. Use [REST API v5.0](https://help.boldreports.com/enterprise-reporting/rest-api-reference/v5.0/) for new integrations.

## Where are the REST API v2.0 reference and Try It Now pages?

The Bold Reports<sup>®</sup> REST API v2.0 has an API reference page and an interactive Try It Now page.
