# Embed Authentication REST API v1.0

When you sign in to Bold Reports<sup>®</sup> Embedded applications, you receive an encrypted authentication token. This token must be included in the Authorization header for secure API requests.

## Where is the Embed Authentication API reference?

The Bold Reports<sup>®</sup> Embed Authentication REST API v1.0 reference lists the endpoints that use this token.

[Rest API - v1.0](https://help.boldreports.com/enterprise-reporting/rest-api-reference/embed-authentication/server-api-reference/)
