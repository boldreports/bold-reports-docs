# Bold Reports<sup>®</sup> Site Administration REST API References

Using the Bold Reports<sup>®</sup> Site Administration REST API, you can manage and change resources in your site programmatically using HTTP. The API gives you simple access to the functionality behind the resources on your site.

## What can I do with the Site Administration REST API?

The Bold Reports<sup>®</sup> Site Administration REST API lets you create your own custom applications or script interactions with your site.

## What is the Site Administration API path?

For the Bold Reports<sup>®</sup> application, the API path is `https://{Domain}/api/{ApiEndpoint}`.

For example, `https://adhoc.boldreports.com/api/token`.

## API Versions

The Bold Reports<sup>®</sup> Site Administration REST API has two versions, v1.0 and v2.0.
