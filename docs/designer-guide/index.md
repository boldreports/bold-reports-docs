# Web Report Designer in Bold Reports<sup>®</sup>

The Bold Reports<sup>®</sup> **Web Report Designer** is a web-based reporting tool that you use to create and edit RDL (Report Definition Language) standard reports. The Web Report Designer comes with a wide range of report items to transform data into information. You build reports with the help of the following features.

## What are the key features of the Web Report Designer?

The Bold Reports<sup>®</sup> Web Report Designer provides the following key features for designing RDL reports.

**Data sources**: The Web Report Designer supports commonly used data sources such as Microsoft SQL Server, Oracle, OLEDB, ODBC, Web API, OData, JSON, and XML.

**Built-in query builder**: The query builder provides a convenient user interface that helps both technical and non-technical users create and view relationships between tables.

**Report items**: The Web Report Designer provides a rich set of report items like text box, image, line, rectangle, table, list, matrix, more than 20 chart types, sub reports, and barcodes for clear visualization of your data.

**Interactive design surface**: You arrange report items on the Web Report Designer surface using drag-and-drop operations. Grid lines and snap-to-grid options make positioning and aligning report items easier.

**Report parameters**: You can create report parameters to specify the data to filter in a report, connect related reports together, and vary report presentation.

**Image manager**: The image manager lets you add and manage embedded images in a report. Embedding an image ensures the image is always available to a report.

**Property panel**: The property panel lets you customize the appearance of report items and edit their property values. You can specify static values or expressions as values in the report item properties.

**Interactive reports**: You can create a report with interactive features provided by RDL reports, such as drill-through and drill-down, to display data and information in detail.

**Manipulate your data**: You can manipulate data with a rich set of features such as sorting, filtering, grouping, and calculated fields.

**Built-in expression editor**: You can create simple and complex RDL reporting expressions. The expression editor supports constants, built-in fields, parameters, data sets, variables, operators, common functions, and more.

**Embedded custom code**: The Web Report Designer supports embedding Visual Basic and .NET code directly within report layouts.
