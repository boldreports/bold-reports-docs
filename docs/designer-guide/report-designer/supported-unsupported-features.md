# Supported and Unsupported Items in Web Report Designer

The Bold Reports<sup>®</sup> Web Report Designer supports most RDL report items, report features, and data sources. The tables below list each item and whether the Web Report Designer supports it.

## Report Items

The following table shows which report items the Bold Reports<sup>®</sup> Web Report Designer supports. Charts such as 3-D Charts, Sunburst, Tree Map Chart, Bullet Graph, Heat Map, and Gantt are not supported, along with Shapes, Checkbox, and TOC.

| Features            | Supported |
|---------------------|-----------|
| Textbox             | Yes       |
| Image               | Yes       |
| Rectangle           | Yes       |
| Line                | Yes       |
| Column Chart        | Yes       |
| Bar Chart           | Yes       |
| Pie Chart           | Yes       |
| Doughnut Chart      | Yes       |
| Pyramid Chart       | Yes       |
| Funnel Chart        | Yes       |
| Area Chart          | Yes       |
| Line Chart          | Yes       |
| Bubble Chart        | Yes       |
| Radar Chart         | Yes       |
| Polar Chart         | Yes       |
| Range Charts        | Yes       |
| 3-D Charts          | No        |
| Sunburst            | No        |
| Tree Map Chart      | No        |
| Bullet Graph        | No        |
| Heat Map            | No        |
| Gantt               | No        |
| Sparkline           | Yes       |
| Data Bar            | Yes       |
| Table               | Yes       |
| Matrix              | Yes       |
| List                | Yes       |
| Gauge               | Yes       |
| Indicator           | Yes       |
| Maps                | Yes       |
| SubReport           | Yes       |
| Barcode             | Yes       |
| Shapes              | No        |
| Checkbox            | No        |
| TOC                 | No        |
| Custom Report Items | Yes       |
