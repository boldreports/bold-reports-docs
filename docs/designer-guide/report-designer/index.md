# {{site.productNameTM}} Web Report Designer

The {{site.productNameTM}} **Web Report Designer** is a web-based reporting tool to create and edit RDL (Report Definition Language) standard reports. It comes with a wide range of report items to turn data into meaningful information, and the following features help you build reports quickly.

## What are the key features of Web Report Designer?

{{site.productNameTM}} Web Report Designer offers the following key features:

**Data sources**: Supports commonly used data sources such as Microsoft SQL Server, Oracle, OLEDB, ODBC, Web API, OData, JSON, and XML.

**Built-in query builder**: Provides a convenient user interface that helps both technical and non-technical users create and view relationships between tables.

**Report items**: Provides a rich set of report items like text box, image, line, rectangle, table, list, matrix, more than 20 chart types, sub reports, and barcodes for clear visualization of your data.

**Interactive design surface**: Arrange report items on the Web Report Designer surface with simple drag-and-drop operations. Grid lines and snap-to-grid options simplify positioning and aligning report items.

**Report parameters**: Supports creating report parameters to specify the data to filter in a report, connect related reports together, and vary report presentation.

**Image manager**: Lets you add and manage embedded images in a report. Embedding an image ensures the image is always available to a report.

**Property panel**: Lets you customize the appearance of report items and edit their property values. You can specify static values or expressions as values in the report item properties.

**Interactive reports**: Supports creating a report with highly interactive features provided only by RDL reports, such as drill through and drill down to display data and information in detail.

**Manipulate your data**: Lets you manipulate data with a rich set of features such as sorting, filtering, grouping, and calculated fields.

**Built-in expression editor**: Create simple and complex RDL reporting expressions. Supports the use of constants, built-in fields, parameters, data sets, variables, operators, common functions, and more.

**Embedded custom code**: Supports embedding Visual Basic and .NET code directly within report layouts.
