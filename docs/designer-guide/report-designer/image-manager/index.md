# Image manager in {{site.productNameTM}} Web Report Designer

The Image Manager in {{site.productNameTM}} Web Report Designer lets you embed local or database images in a report. The image data is stored within the report definition.

## How are embedded images stored?

When you embed an image in {{site.productNameTM}} Web Report Designer, the image is MIME-encoded and stored as text in the report definition. The embedded images in a report are listed in the **Image Manager panel**.
