# Modify shared dataset

You modify a shared dataset in the Bold Reports<sup>®</sup> Web Report Designer by choosing `Edit` from the dataset context menu in the `DATA` panel. Editing changes the data feed for your report.

## How do I edit a shared dataset?

You edit a shared dataset from the `DATA` panel of the Bold Reports<sup>®</sup> Web Report Designer with the following steps:

1. Select the data in the `DATA` panel that you want to edit.

   ![Data item menu icon](/static/assets/on-premise/images/report-designer/manage-data/dataset/data-item-menu-icon.png '#width=385px')

2. Click the highlighted icon shown in the previous image to open the `Edit` context menu of the selected data.

   ![Data panel context menu](/static/assets/on-premise/images/report-designer/manage-data/dataset/data-panel-context-menu.png '#width=385px')

3. Choose the `Edit` option from the context menu. The edit panel opens, where you can make your changes.

   ![Query designer edit view](/static/assets/on-premise/images/report-designer/manage-data/dataset/edit-shared-data-panel.png '#width=385px')

4. After you modify the fields, click the `Save` button.
