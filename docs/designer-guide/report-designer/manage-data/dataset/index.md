# Report data sets in Bold Reports<sup>®</sup> Web Report Designer

A dataset in the Bold Reports<sup>®</sup> Web Report Designer contains a query and a collection of fields that represent the data returned from the data source.

## What is an embedded data set?

An embedded data set in Bold Reports<sup>®</sup> is specific to a single report and stores the query used to process the report data. You can create a data set using an embedded or shared data source. In an embedded data set, you can add query parameters, filters, and table relationships, and set the query string as an expression.

## What is a shared data set?

A shared data set is a dataset published on a Bold Reports<sup>®</sup> Report Server that you add to your report, like a shared data source. It provides an easy way to change a query in one place and reflect the change in the referring reports.
