# Keyboard shortcuts in Bold Reports<sup>®</sup> Web Report Designer

Bold Reports<sup>®</sup> Web Report Designer lets you design a report using only the keyboard, without a mouse. Use the following shortcut keys to work with the web designer.

## Frequently asked questions

### How do I show or hide the header with the keyboard?

Press <kbd>Alt + H</kbd> to enable or disable the header, and <kbd>Alt + F</kbd> to enable or disable the footer.

### How do I resize a selected report item with the keyboard?

Press <kbd>Shift + Arrow keys</kbd> to resize the selected report item. Use <kbd>Ctrl + Shift</kbd> with an arrow key to increase or decrease its width or height.
