# Property Navigator in {{site.productNameTM}} Web Report Designer

The **Property Navigator** in {{site.productNameTM}} Web Report Designer displays the report structure in a hierarchical format. You can quickly locate and select report elements to configure.

![Property Navigator interface showing hierarchical report structure](/static/assets/on-premise/images/report-designer/compose-report/property-navigator/property-navigator-user-interface.png '#width=350px')

## How do I open the Property Navigator?

You open the **Property Navigator** in Web Report Designer from the **Properties Panel**. First, click the `Properties` icon to open the **Properties Panel**.
![Properties panel icon for opening Property Navigator](/static/assets/on-premise/images/report-designer/compose-report/property-navigator/properties-icon.png '#width=350px')

Next, click the highlighted `Property Navigator` icon. The popup list appears.
![Popup list of Property Navigator with report elements](/static/assets/on-premise/images/report-designer/compose-report/property-navigator/property-navigator-popup-list.png '#width=350px')

## How does the Property Navigator show report elements?

The Property Navigator popup list in Web Report Designer shows the report structure in a hierarchical format. Each report element is shown by its name and type. In the example below:

* The icon and the tag (Image) indicate the type of the report item.

* `Logo_Image` is the name of the report item.

![Property Navigator hierarchy view showing element type and name](/static/assets/on-premise/images/report-designer/compose-report/property-navigator/report-element-denotion.png '#width=350px')

## How do I search for a report element?

You search for a report element in the Property Navigator popup list by typing its name in the search option. The results are displayed in a **parent-child hierarchical** format.
![Search results in Property Navigator with parent-child hierarchy](/static/assets/on-premise/images/report-designer/compose-report/property-navigator/search-with-match.png '#width=350px')

If no results are found, a `No matches found` message appears.
![Property Navigator search error message](/static/assets/on-premise/images/report-designer/compose-report/property-navigator/search-with-no-match.png '#width=350px')

## How do I select an element and close the navigator?

Selecting a report section (such as Report, Header, Body, or Footer) or a report item in the Property Navigator displays its properties in the Properties Panel.
![Selecting report items in Property Navigator highlights properties](/static/assets/on-premise/images/report-designer/compose-report/property-navigator/report-item-selection-tick.png '#width=350px')

To close the Property Navigator popup list, click anywhere outside the popup area.

## Frequently asked questions

### What happens when a search finds no report element?

The Property Navigator shows a `No matches found` message.

### Which sections can I select in the Property Navigator?

You can select a report section such as Report, Header, Body, or Footer, or a specific report item. Its properties then appear in the Properties Panel.
