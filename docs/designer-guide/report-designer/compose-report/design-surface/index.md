# Design surface in Bold Reports<sup>®</sup> Web Report Designer

The Bold Reports<sup>®</sup> Web Report Designer comes with a WYSIWYG design surface. You edit a report in a form that resembles its appearance when printed or displayed.

## What can I do on the design surface?

The Web Report Designer design surface provides these key features for arranging report items:

* Arrange report items on the Web Report Designer surface using drag-and-drop operations.

* Grid lines and snap-to-grid options simplify the positioning and aligning of report items.

* You can resize a report item in eight different directions to keep its shape. You can also resize multiple objects at the same time.

* When multiple report items overlap in the design surface, the layout ordering controls which report item is at the top and which is at the bottom.

* Enhanced alignment options allow perfect positioning, sizing, and aligning of report items in a report.

* You can distribute selected report items on the design surface at equal intervals from each other.

* You can perform basic designing actions using the design surface context menu.
