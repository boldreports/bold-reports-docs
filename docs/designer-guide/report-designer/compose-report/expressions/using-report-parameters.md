# Parameters in Web Report Designer expressions

In {{site.productNameTM}} Web Report Designer, the parameters available in the report are listed in the **Data** drop-down list of the expression editor. You can add any of these parameters to an expression.

![list-of-parameter-dropdown](/static/images/report-designer/compose-report/expressions/parameter-dropdown.png '#width=400px')

## How do I add a parameter to an expression?

The Web Report Designer adds a report parameter to an expression when you double-click it in the parameters list.

1. After you create report parameters, they are listed in the list view. Double-click any report parameter.
   ![parameter collection in list view](/static/images/report-designer/compose-report/expressions/choose-parameter.png '#width=200px')

2. The parameter field value is shown as an expression in the text area. Click **OK** to save the selected expression.
   ![selected-parameter-textarea](/static/images/report-designer/compose-report/expressions/selected-parameter.png '#width=400px')
