# How to configure timeout setting for data connectors

Bold Reports<sup>®</sup> On-Premises Edition lets you configure the data connector timeout setting on the UMS configuration page. This setting applies to HTTP requests made by data connectors.

## How do I configure the timeout setting?

You configure the data connector timeout for Bold Reports<sup>®</sup> On-Premises Edition on the UMS configuration page. For configuration steps, read the [Configure Timeout Setting](../../../../administrator-guide/how-to/customize-timeout-settings/) section.

## Supported Data Connectors

The following Bold Reports<sup>®</sup> data connectors support the timeout setting:

* [ODATA](./../../manage-data/data-connectors/odata-data-source/#configure-timeout-setting)
* [Web API](./../../manage-data/data-connectors/rest-api-data-source/#configure-timeout-setting)
