# How to configure timeout setting for data connectors

{{site.productNameTM}} On-Premises Edition lets you configure the data connector timeout setting on the UMS configuration page. This setting applies to HTTP requests made by data connectors.

## How do I configure the timeout setting?

You configure the data connector timeout for {{site.productNameTM}} On-Premises Edition on the UMS configuration page. For configuration steps, read the Configure Timeout Setting section in the Administrator Guide.

## Supported Data Connectors

The following {{site.productNameTM}} data connectors support the timeout setting:

* [ODATA](./../../manage-data/data-connectors/odata-data-source/#configure-timeout-setting)
* [Web API](./../../manage-data/data-connectors/rest-api-data-source/#configure-timeout-setting)
