# Configure report items in Bold Reports<sup>®</sup> Web Report Designer

The Bold Reports<sup>®</sup> Web Report Designer offers a rich set of report items to present data in comprehensive reports. These items help companies make better business decisions.

## Which report items are available?

The Bold Reports<sup>®</sup> Web Report Designer groups its report items as follows:

* Basic Items: text box, image, line, and rectangle.
* Data region items: tablix, matrix (pivot), and list.
* Data visualization: 20+ chart types.
* Data bar
* Sparkline
* Indicator
* Linear Gauge
* Radial Gauge
* Subreport
* Map
* Custom report items: barcode and QR code.
