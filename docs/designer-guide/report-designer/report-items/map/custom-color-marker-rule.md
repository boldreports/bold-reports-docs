# Custom color rule for map markers in Bold Reports<sup>®</sup>

In the Bold Reports<sup>®</sup> Web Report Designer, the custom color rule lets you specify any number of color sets. The rule applies a fill color to each map marker icon by cycling through the provided colors.

## How do I apply a custom color rule to map markers?

You apply a custom color rule to map markers in the Bold Reports<sup>®</sup> Web Report Designer from the `Marker Color Rule` category.

1. Under the `Marker Color Rule` category, choose the **Custom** option in the type dropdown.
2. Use the **Custom Colors** field that appears under the type dropdown to set your colors.

![Map palette types](/static/assets/on-premise/images/report-designer/report-items/map/marker-color-rule/custom-colors-field.png '#width=445px')

## How do I define the custom colors?

The Bold Reports<sup>®</sup> custom color option lets you define any number of color sets based on the output you want. To define custom colors, see the [Custom colors](./../../../report-items/map/define-custom-colors/) section.
