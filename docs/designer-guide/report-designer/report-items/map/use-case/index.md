# Map use cases in Bold Reports<sup>®</sup> Web Report Designer

The Bold Reports<sup>®</sup> Web Report Designer map use cases show how to design map reports with shape color rules, marker rules, and marker color rules. Each use case walks you through creating the data, binding it to the map, and customizing the map.
