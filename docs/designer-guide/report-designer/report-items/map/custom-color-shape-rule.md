# Custom color rule for map shapes in {{site.productNameTM}}

In the {{site.productNameTM}} Web Report Designer, the custom color rule lets you specify any number of color sets. The rule applies a fill color to each map shape in a layer by cycling through the provided colors.

## How do I apply a custom color rule to map shapes?

You apply a custom color rule to map shapes in the {{site.productNameTM}} Web Report Designer from the `Shape Color Rule` category.

1. Under the `Shape Color Rule` category, choose the **Custom** option in the type dropdown.
2. Use the **Custom Colors** field that appears under the type dropdown to set your colors.

![Map palette types](/static/assets/on-premise/images/report-designer/report-items/map/shape-color-rule/custom-colors-field.png '#width=445px')

The {{site.productNameTM}} custom color option lets you define any number of color sets based on the output you want. To define custom colors, see the [Custom colors](./../../../report-items/map/define-custom-colors/) section.

## Is there a use case example?

Yes. See the [Design map using custom color rule](./../../../report-items/map/use-case/design-map-using-custom-rule/) section. It designs the annual gross domestic product (GDP) growth rate of each country for the year 2019 to produce a display similar to a heat map in the {{site.productNameTM}} map report item.
