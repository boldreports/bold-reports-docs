# Upgrade to Bold Reports<sup>®</sup> from classic platform

You can upgrade a classic platform Report Server to Bold Reports<sup>®</sup> Enterprise Reporting manually at any time.

## Which upgrade guide should I use?

Bold Reports<sup>®</sup> provides one upgrade guide for each classic platform Report Server. Choose the guide that matches your current version:

* [Upgrade Syncfusion<sup>®</sup> Report Server v4.x to Bold Reports<sup>®</sup>](./../on-premises/upgrade-from-classic-platform/data-migration/)
* [Upgrade Bold Reports<sup>®</sup> from v1.x](./../on-premises/upgrade-from-classic-platform/upgrade-bold-reports-from-v1.x-to-latest/)

## What permissions does the upgrade need?

The Bold Reports<sup>®</sup> upgrade needs the user to have all the required permissions during the upgrade process.

> **Note:** During the upgrade process, grant all the required permissions to the user. Make sure that users have the necessary [database permissions to set up Bold Reports<sup>®</sup>](../../../administrator-guide/faq/what-are-the-database-permissions-required-to-set-up-bold-reports/).
