# Upgrade to Bold Reports<sup>®</sup> from classic platform

You can upgrade a classic platform Report Server to Bold Reports<sup>®</sup> Enterprise Reporting manually at any time.

## Which upgrade path should I follow?

Bold Reports<sup>®</sup> provides a separate upgrade guide for each classic platform Report Server. Pick the guide that matches the version you run today:

* [Upgrade Syncfusion<sup>®</sup> Report Server v4.x to Bold Reports<sup>®</sup>](./../../deployment/upgrade/on-premises/upgrade-from-classic-platform/data-migration/)
