# Create and upgrade Bold Reports<sup>®</sup> Azure App Service

Bold Reports<sup>®</sup> On-Premises Edition lets you create Report Server as an Azure App Service using an ARM template. Deploying it as an Azure App Service helps you easily scale up your Report Server application on demand.

## Which upgrade guides are available for Azure App Service?

Bold Reports<sup>®</sup> provides upgrade guides for Azure App Service from Bold Reports<sup>®</sup> v1.x and v2.x, and from Syncfusion<sup>®</sup> Report Server v4.x. You can upgrade Bold Reports<sup>®</sup> Azure App Service to a later version.

Use the following guides to create and upgrade your Azure App Service.

[Upgrade Bold Reports<sup>®</sup> Azure App Service from v1.x](./../azure/upgrade-v1.x/)

[Upgrade Bold Reports<sup>®</sup> Azure App Service from v2.x](./../azure/upgrade-app-service/)

[Upgrade Syncfusion<sup>®</sup> Report Server Azure App Service from v4.x](./../azure/migrate-syncfusion-report-server-app-service/)

## What permissions do I need to upgrade?

Bold Reports<sup>®</sup> upgrades need the user to have all the required database permissions.

> **Note:** During the upgrade process, grant all the required permissions to the user. Make sure that users have the necessary [database permissions to set up Bold Reports<sup>®</sup>](../../../administrator-guide/faq/what-are-the-database-permissions-required-to-set-up-bold-reports/).
