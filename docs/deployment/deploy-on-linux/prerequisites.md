# Prerequisites to deploy Bold Reports<sup>®</sup> on Linux

Bold Reports<sup>®</sup> On-Premises Edition on Linux needs a 4-core CPU, 16 GB of RAM, 10 GB of disk space, a supported database and an Nginx or Apache web server. Check these requirements before you install.

## Hardware requirements

Bold Reports<sup>®</sup> On-Premises Edition needs the following hardware to run on Linux:

* **Operating System:** Bold Reports<sup>®</sup> for Linux can run on various Linux distributions and has been verified on the following operating systems:
    * Ubuntu 20.04+
    * Cent OS Stream 9+
    * Oracle Linux 9.2+
    * Red Hat Enterprise Linux 9.3+
    * Alma Linux OS 9.5
    * Debian 12
    * Rocky Linux 8+
* **CPU:** 4-Core.
* **RAM:** 16 GB.
* **Disk Space for Installation Files:** 10 GB.

## Software requirements

Bold Reports<sup>®</sup> On-Premises Edition needs the following software to run on Linux:

* **Database:** PostgreSQL 13.0+ | Microsoft SQL Server 2016+ | MySQL 8.0+ | Oracle Database 19c+.
* **Web Server:** [Nginx](https://learn.microsoft.com/en-us/aspnet/core/host-and-deploy/linux-nginx?view=aspnetcore-3.1&tabs=linux-ubuntu#install-nginx) | [Apache](https://learn.microsoft.com/en-us/aspnet/core/host-and-deploy/linux-apache?view=aspnetcore-3.1).
* **Web Browser:** Microsoft Edge | Mozilla Firefox | Chrome | Apple Safari.

## Frequently asked questions

### Which Linux distributions has Bold Reports<sup>®</sup> been verified on?

Bold Reports<sup>®</sup> for Linux has been verified on Ubuntu 20.04+, Cent OS Stream 9+, Oracle Linux 9.2+, Red Hat Enterprise Linux 9.3+, Alma Linux OS 9.5, Debian 12 and Rocky Linux 8+.

### Which databases does Bold Reports<sup>®</sup> support on Linux?

Bold Reports<sup>®</sup> On-Premises Edition on Linux supports PostgreSQL 13.0+, Microsoft SQL Server 2016+, MySQL 8.0+ and Oracle Database 19c+.
