# Deploying in Alibaba Cloud Kubernetes Cluster (ACK Cluster)

Bold Reports<sup>®</sup> can be deployed on an Alibaba Cloud Kubernetes (ACK) cluster. You can create the Alibaba Cloud Kubernetes cluster on either cloud or on-premises infrastructure.

## How do I deploy Bold Reports<sup>®</sup> on Alibaba Cloud Kubernetes?

To deploy Bold Reports<sup>®</sup> on Alibaba Cloud Kubernetes, first complete the cluster creation. Then, follow the [Bold Reports<sup>®</sup> on Alibaba Cloud deployment guide on GitHub](https://github.com/boldreports/bold-reports-kubernetes/blob/master/docs/alibaba-ack.md). The guide covers deployment in specific cloud and on-premises environments.

## Frequently asked questions

### Can I run the ACK cluster on-premises?

Yes. Bold Reports<sup>®</sup> supports an Alibaba Cloud Kubernetes cluster created on either cloud or on-premises infrastructure.

### What must I do before deploying Bold Reports<sup>®</sup> on ACK?

You must complete the Alibaba Cloud Kubernetes cluster creation before you deploy Bold Reports<sup>®</sup>.
