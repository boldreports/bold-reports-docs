# Prerequisites to use Bold Reports<sup>®</sup> server on GCP

To use the Bold Reports<sup>®</sup> Report Server on GCP, you need a GCP subscription, a Bold Reports<sup>®</sup> license, and Remote Desktop.

## What do I need before deploying on GCP?

Bold Reports<sup>®</sup> Report Server on GCP needs the following items:

  1. GCP subscription with required privileges.
  2. You need Bold Reports<sup>®</sup> Server. Make sure you have the appropriate license, and download the build by following the instructions in the [registration and download help](../../../deployment/getting-started/#registration-and-download).
  3. Remote Desktop must be installed on your computer. You need it to sign in to the Virtual Machine (VM) where the Bold Reports<sup>®</sup> Server is installed. Remote Desktop comes pre-installed on Windows-based operating systems.

> **NOTE:** If you are using a Mac, the Remote Desktop client can be installed from the provided [Remote Desktop client](https://www.microsoft.com/en-us/p/microsoft-remote-desktop/9wzdncrfj3ps?activetab=pivot:overviewtab). For Linux users, you can use [rdesktop](http://www.rdesktop.org/) to connect to your instance running Microsoft Windows.

## Frequently asked questions

### How do I connect to a GCP Windows instance from a Mac or Linux machine?

To reach the Bold Reports<sup>®</sup> Server VM from a Mac, install the [Remote Desktop client](https://www.microsoft.com/en-us/p/microsoft-remote-desktop/9wzdncrfj3ps?activetab=pivot:overviewtab). On Linux, use [rdesktop](http://www.rdesktop.org/).
