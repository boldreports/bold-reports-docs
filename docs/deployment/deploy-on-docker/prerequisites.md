# Prerequisites for deploying Bold Reports<sup>®</sup> on Docker

To deploy Bold Reports<sup>®</sup> on Docker with docker-compose, your machine must meet the hardware and software requirements on this page.

## Prerequisites

Bold Reports<sup>®</sup> on Docker with docker-compose needs a machine that meets the following hardware and software requirements.

### What hardware do I need?

Bold Reports<sup>®</sup> needs the following hardware to run the solution:

* **Operating System:** You can use Bold Reports<sup>®</sup> Docker on the following operating systems:
    * Windows
    * Linux 22.04 LTS
    * Mac
* **CPU:** 4-Core.
* **RAM:** 16 GB.
* **Disk Space for Installation Files:** 10 GB.

### What software do I need?

Bold Reports<sup>®</sup> On-Premises Edition needs the following software:

* **Database:** PostgreSQL 13.0+| Microsoft SQL Server 2016+ | MySQL 8.0+ | Oracle Database 19c+.
* **Application:** Docker Engine and Docker Compose (for Linux users) | Docker Desktop / Rancher Desktop (for Windows and Mac users).
* **Web Browser:** Microsoft Edge, Mozilla Firefox, Chrome and Apple Safari.

## Frequently asked questions

### Which databases does Bold Reports<sup>®</sup> support on Docker?

Bold Reports<sup>®</sup> on Docker supports PostgreSQL 13.0+, Microsoft SQL Server 2016+, MySQL 8.0+, and Oracle Database 19c+.

### How much RAM does Bold Reports<sup>®</sup> need on Docker?

Bold Reports<sup>®</sup> on Docker needs 16 GB of RAM, a 4-core CPU, and 10 GB of disk space for installation files.
