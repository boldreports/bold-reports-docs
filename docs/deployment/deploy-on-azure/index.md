# Deploying Bold Reports<sup>®</sup> Application in Azure App Service

You can deploy Bold Reports<sup>®</sup> Enterprise Edition in the Microsoft Azure portal by following the guides listed on this page. The guides also offer a recommended configuration for your Azure Virtual Machine (VM).

The Bold Reports<sup>®</sup> Azure deployment guides cover each stage of running Enterprise Reports in Azure:

* [Prerequisites](../deploy-on-azure/prerequisites/)

* [Recommended Azure App service configuration](../deploy-on-azure/vm-configuration/)

* [Self-deploy a Bold Reports<sup>®</sup> Server on Microsoft Azure](../deploy-on-azure/self-deploy-bold-reports-on-azure-vm/)

* [Bold Reports<sup>®</sup> in Microsoft Azure Marketplace](../deploy-on-azure/bold-reports-in-azure-marketplace/)

* [Upgrade the VM to a Newer Version](../deploy-on-azure/upgrade-vm-to-latest-version/)

Start with the Bold Reports<sup>®</sup> [Azure prerequisites](../deploy-on-azure/prerequisites/), then review the [recommended Azure VM configuration](../deploy-on-azure/vm-configuration/) before you deploy.
